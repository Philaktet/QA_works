# Wikipedia UI Тесты (Cypress)

**Назначение**: Автоматизированные end-to-end тесты ключевых функций Wikipedia  
**Технологии**: Cypress 14.5.2


## Содержание тестов

| Файл | Тестируемая функция |
|-------|---------------------|
| 1-basic-loading.cy.js | Проверка загрузки главной страницы |
| 2-article-search.cy.js | Поиск статей и валидация результатов |
| 3-navigation.cy.js | Проверка меню навигации | 
| 4-language.cy.js | Переключение языковых версий ru-en |
| 5-article-lifecycle.cy.js | Цикл взаимодействий поиск → чтение → переход → возврат |

## 🚀 Запуск тестов

### Предварительные требования
- Node.js v22.17.1
- Yarn (менеджер пакетов, используется в проекте)

### Инструкция
1.  **Склонируйте репозиторий:**
    ```bash
    git clone https://github.com/Philaktet/QA_works.git
    ```

2.  **Перейдите в папку с тестами:**
    ```bash
    cd ./E2E_tests
    ```
3.  **(Опционально) Используйте корректную версию Node.js (через nvm):**
    ```bash
    nvm install
    nvm use
    ```  
    
4.  **Установите зависимости с помощью Yarn:**
    ```bash
    yarn install
    ```

5.  **Запустите тесты одним из двух способов:**

    #### Способ 1: Запуск в Interactive Mode (с графическим интерфейсом Cypress)
    ```bash
    yarn start
    ```
    После выполнения команды:
    - В открывшемся окне Cypress нажмите **"E2E Testing"**.
    - Выберите браузер (например, **Chrome**).
    - Нажмите кнопку **"Start E2E Testing in Chrome"**.
    - Во вкладке браузера выберите нужный тест для запуска.

    #### Способ 2: Запуск в Headless Mode (в терминале)
    *Тесты запустятся в фоновом режиме, а результаты будут выведены в терминал.*
    ```bash
    yarn test
    ```
